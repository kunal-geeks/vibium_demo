# Vibium Demo Project

A beginner-friendly Vibium automation project using the JavaScript API.

## Features
- Browser automation with Vibium
- Screenshot capture on failure
- SauceDemo negative login test
- Clean, modular structure

## Run
npm install
npm run hello
npm run negative

🧠 What I Learned

- Browser automation fundamentals
- Using Vibium’s sync and async APIs
- Handling negative test scenarios
- Debugging async JavaScript issues
- Capturing screenshots on failures
- Structuring a clean automation project
